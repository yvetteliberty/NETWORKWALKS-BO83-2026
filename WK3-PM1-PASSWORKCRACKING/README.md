 # 🎯 PASSWORD CRACKING USING JOHN THE RIPPER AND NETWORKWALKS TOOL
Password cracking is the process of recovering or determining an unknown password from stored data, hashes, or protected files. In cybersecurity and ethical hacking, it is a crucial technique used to evaluate the strength of authentication credentials and demonstrate the vulnerabilities of weak passwords.
Many modern systems and encrypted documents (such as PDFs, archives, and Office files) do not store plaintext passwords. Instead, they store a cryptographic hash-a scrambled, one-way mathematical representation of the password. The hash or encrypted structure is extracted from the target file or system (e.g., pulling a PDF hash starting with $pdf$). A cracking tool tests various passwords against the extracted hash or file.When a  string yields a matching hash, the original plaintext password is successfully recovered.

# 📌 Project Overview
This project focuses on downloading, installing, and using the John the Ripper GUI to recover passwords from password-protected PDF, ZIP, and Microsoft Office documents.

The project also uses two free online tools developed by NetworkWalks: the Hash Calculator and the Password Cracker. The Hash Calculator is used to extract the hash from a locked PDF file, while the Password Cracker is used to attempt to recover the original password from the extracted hash.
Through this project, I will gain a better understanding of how password cracking works step by step and learn why using strong, secure passwords is important for protecting sensitive information.
